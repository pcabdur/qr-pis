# Security Policy

## Supported Version

QR-PIS is currently under active development.

Only the latest version available in the `main` branch is supported with security updates and bug fixes.

| Version | Supported |
|----------|-----------|
| Latest (main) | ✅ |
| Older versions | ❌ |

---

## Reporting a Security Vulnerability

If you discover a security vulnerability in QR-PIS, please report it privately instead of creating a public GitHub issue.

### Contact

📧 Email: pcabdur@gmail.com

Please include:

- Description of the vulnerability
- Steps to reproduce
- Expected behavior
- Potential impact
- Screenshots or logs (if applicable)

---

## Response Timeline

I aim to:

- Acknowledge reports within **48 hours**
- Investigate valid reports within **7 days**
- Release a fix as soon as possible if the issue is confirmed

---

## Scope

This policy applies to:

- Flask Backend
- Machine Learning Prediction API
- QR Code Processing
- AWS Infrastructure
- Terraform Configuration

---

## Responsible Disclosure

Please do not publicly disclose security vulnerabilities until they have been investigated and fixed.

I appreciate responsible disclosure and will acknowledge contributors who help improve the security of this project.
